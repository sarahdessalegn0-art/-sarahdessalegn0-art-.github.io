How JavaScript If / Else Statements Work

An if statement is used to make decisions and run code only when a condition is true.

1. The if Statement

If the condition inside the parentheses is true, the code inside the curly braces runs.

let score = 85;

if (score > 70) {
  console.log("You passed!");
}

2. The if...else Statement

Use an else statement to run alternative code if the condition is false.

let age = 16;

if (age >= 18) {
  console.log("You can vote.");
} else {
  console.log("You cannot vote yet.");
}

3. The else if Statement

Use else if when you have multiple conditions to check in order.

let time = 14;

if (time < 12) {
  console.log("Good morning!");
} else if (time < 18) {
  console.log("Good afternoon!");
} else {
  console.log("Good evening!");
}
