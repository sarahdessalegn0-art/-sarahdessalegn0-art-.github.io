How JS if/else statements work

So basically, an if/else statement is how you get your code to make decisions. You give it a condition, and depending on whether that condition is true or false, it runs different blocks of code.

1. The basic if statement

This is the simplest one. You put a condition in parentheses. Whatever is inside the curly brackets runs if its true. Otherwise, the code just skips it completely if its false.

2. The if...else statement

This is when you want a backup plan. It does one thing if the main condition is true. But if it's false, it drops down to the else block and does that instead.

3. The else if statement

You chain a bunch of these together if you have more than two options to check. It checks them in order from top to bottom, and as soon as it finds one that works, it runs that code and ignores the rest.
